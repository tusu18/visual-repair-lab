# Boundaries and persistence

Three roles stay separate. The generator/teacher uses only train grammar, train records and learner outcomes. Its image excludes the held-out family and evaluator modules. The evaluator holds targets, settings, certificates, grading cases and persistent episode databases. The actor receives HTTP public contexts and PNGs; its image contains no evaluator, generator, bank, database, Docker socket or reference source.

Native benchmark calls disable local code, shell, browsing, apps, tools and memory discovery. Exact prompts, image bindings/hashes, schema, public responses, usage and actions are recorded. The final baseline attaches one current image per decision, with its observation/revision binding; earlier action summaries remain in history. Private settings and grader sidecars never enter actor inputs.

SQLite uses full synchronous commits, idempotent request IDs, expected-step checks and bounded replay workers. An identical retry does not execute again. A worker/transport failure does not consume a committed action or earn a score. Changed source/bank seals require a new database. Persist pending decisions before posting; recover saved successful model responses after crashes.

Capacity refusals are infrastructure interruptions, not seeing/coding failures. Additive continuation preserves failed calls and original results, reuses the same episode and successful decision prefix, and keeps model/provider/effort and remaining budget unchanged. It is not a fresh independent attempt.

The benchmark has archived frozen sources. Final trainer integration adds stricter catalogue admission, teacher and Gym checks. Replay uses frozen sources, with delivery observation/reward parity checked separately rather than claiming all files are byte-identical.

This is a local research service, not a hardened public multi-tenant platform. A bounded interpreter is not an OS security boundary. Keep actor filesystems separate.

The private detection family is held out from this generator and calibration actors. Pairwise IoU suppression and categorical class remapping are absent from the train rule grammar. This does not imply absence from model pretraining. Release source reveals the family implementation, so future external evaluations need new private manifests and possibly additional unseen families. Evaluated private manifests are excluded from the distributable bank.
